# Shared resources

Noema is the source of truth for the static editor assets in this directory:

- `snippets/`: YASnippet catalogs shared by Noema and Emacs
- `templates/`: Markdown, LaTeX, and programming-language templates
- `katex-macros/`: global TeX macros used by KaTeX
- `prose-accepted-words.txt`: accepted words for prose diagnostics

The Emacs configuration links its historical asset paths here so existing
Emacs packages and configuration continue to work unchanged.
