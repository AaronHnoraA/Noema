# Noema Latin Modern prose fonts

These WOFF2 files are Latin-only subsets of Latin Modern Roman 10 version
2.005 from TeX Live 2026. Latin Modern was designed by Bogusław Jackowski and
Janusz M. Nowacki from Donald Knuth's Computer Modern family.

The subsets retain the upstream regular, italic, bold and bold-italic faces and
the Unicode ranges declared in `../typography.css`. They were generated with
FontTools `pyftsubset` and encoded with Google's `woff2_compress`; no font
generation runs in Noema's build or at runtime.

The derived files use Noema-specific filenames and the CSS family name
`AaronLatinModernRoman`. They remain distributed under the GUST Font License
in `GUST-FONT-LICENSE.txt`.
